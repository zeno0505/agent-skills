# 주간 교훈 블로그 이미지

주간 교훈 글에 넣을 **그림 후보**를 만든다. 글 본문·말투·교훈 심사는 `weekly-lesson-draft` 스킬이 담당한다. 이 스킬은 초안 스킬이 **이미지 슬롯을 정한 뒤** 호출한다.

## Inputs
- 대상 글의 제목·섹션 목록(또는 승인 전 초안 전문)
- 섹션별 이미지 슬롯: 한 줄 의도 + 넣을 위치(섹션 위/아래)
- 공개 제약: 제품 UI·회사명·실명·내부 ID·미공개 수치 금지(초안 스킬과 동일)

## Hard rules
1. **장식용 금지.** 교훈을 설명하지 않는 분위기 이미지는 만들지 않는다.
2. **공개 필터.** 실제 제품 스크린샷·고객 데이터·내부 도구 UI를 그대로 쓰지 않는다. 필요하면 추상 목업·도식으로 대체한다.
3. **수단 우선순위** (앞에서 되면 뒤는 쓰지 않는다):
   1. mermaid / SVG / 단순 도식(코드로 렌더)
   2. Slidev 한 장 → PNG(`slidev-pdf` 스킬의 빌드·렌더 절차 재사용)
   3. 이미지 생성 모델 — 개념도·아이콘 수준만. 차트·표는 코드로.
4. **폰트(도식·슬라이드 텍스트):** 기본은 **Noto Sans CJK** (`NotoSansCJK-Regular.ttc` / `NotoSansCJK-Bold.ttc`, index 0). 작성자가 다른 폰트를 지정하기 전까지 바꾸지 않는다. Nanum 등 다른 글꼴로 되돌리지 말 것.
5. **카드·박스 세로 정렬.** 둥근 카드·패널 안 텍스트·배지·아이콘 묶음은 **세로 중앙**. 상·하 패딩 대칭. PIL에서는 콘텐츠 높이로 센터 오프셋을 계산한다.
6. **과여백 금지.** 카드·캔버스는 **콘텐츠에 맞춰** 크기를 잡는다. 카드 패딩 16–28px. 카드 높이 ≈ 콘텐츠+상하패딩×2. 바깥 마진 24–40px. 고정 큰 박스에 글만 넣는 방식 금지.
7. **가로·종횡비.** 캔버스 너비 **고정 금지**(1200px 등). 콘텐츠 최소 폭+마진. 블로그용 **직사각형** 기본(대략 1:1~4:3, 최대 ~3:2). 배너형(넓은 가로 띠) 금지. 가로가 과하면 2열 그리드·세로 스택·개행으로 줄인다.
8. **분량.** 글당 보통 1~3장. 슬롯이 비면 「이미지 없음」.
9. **초안만.** 커밋·Pages 배포 금지. 파일은 채팅 첨부 또는 초안 폴더.
10. **작성자 리뷰.** 승인 전 확정 금지. **작성자에게 보이기 전에** 아래 Self-QA를 통과해야 한다.

## Self-QA (작성자 제출 전 필수 — 이 리뷰를 매회 대신한다)
렌더 직후, 작성자에게 보여주기 **전에** 각 장마다 전부 확인한다. 하나라도 실패하면 **재렌더**하고 다시 검수한다. 작성자에게 「여백/정렬/비율」을 물어보며 반복 수정하는 루프를 만들지 않는다.

| # | 검사 | 실패 시 |
|---|------|--------|
| A | 폰트 = Noto Sans CJK (지정 변경 없을 때) | 재렌더 |
| B | 카드 안 세로 중앙 · 상단≈하단 패딩 | 센터 재계산 후 재렌더 |
| C | 카드/캔버스가 콘텐츠에 밀착 (흰 면 ≫ 글 아님) | 높이·패딩 축소 후 재렌더 |
| D | 너비 고정 아님 · 배너형 아님 · 종횡비 ~1:1–4:3 | 스택/2×2/개행으로 레이아웃 변경 후 재렌더 |
| E | 공개 필터 통과 · 교훈 설명용 | 폐기 또는 추상화 |
| F | alt + 삽입 위치 + 마크다운 예시 준비됨 | 보완 후 제출 |

검수 통과분만 초안 스킬/작성자에게 넘긴다. 작성자 리뷰는 **내용·교훈 적합성·넣을지 여부**에 집중하게 하고, 레이아웃 미세조정은 Self-QA에서 끝낸다.

## Steps
1. 초안 스킬이 넘긴 슬롯을 확인한다. 없으면 슬롯 후보만 제안하고 멈춘다.
2. 슬롯마다 수단을 고른다(위 우선순위).
3. **콘텐츠 폭·높이를 먼저 잰 뒤** 카드·캔버스를 잡는다. Noto Sans CJK로 렌더. 규칙 5·6·7 적용. 파일명 `YYYY-MM-DD-<slug>-NN.png`.
4. **Self-QA 표(A–F)를 장마다 통과**한다. 실패 시 재렌더.
5. 통과분에 alt·삽입 위치·마크다운을 붙인다.
6. 초안 스킬로 돌려보낸다. 작성자 탈락분은 버리고, 통과분만 발행 입력으로 넘긴다.

## Output shape
```
- slot: <섹션 제목 또는 id>
  path: <local file>
  alt: "…"
  insert_after: <heading>
  markdown: "![…](assets/…)"
  self_qa: pass  # A–F 전부
```

## Out of scope

- 테마/CSS 대공사, OG 이미지 SEO 최적화
- 승인 없는 커밋·푸시
